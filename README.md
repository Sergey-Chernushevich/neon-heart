# neon-heart

Управляй светящейся платформой — отбивай мяч и круши кирпичи. По пути лови паверапы: BIG расширяет платформу, SLW замедляет мяч, x3 множит шары на поле. Четыре уровня с разными раскладками — от алмазных кластеров до плотных блоков с дырами. Три жизни, и если не удержишь последний шар — игра окончена.
